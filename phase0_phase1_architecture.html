Part 1: Phase 0 — Data Loading & Graph Ingestion

Transactional Delta Lake storage and memory-safe streaming on Amazon S3

Phase 0 transforms raw graph data from SNAP, OGB, and PyG into five ACID-compliant Delta Lake tables on S3. Storing graphs as columnar Delta tables ensures phase-level checkpoint reuse, ACID transaction logs, and prevents worker out-of-memory errors during downstream training.

Delta Table Path Schema Definition Description & Role in Pipeline
original_nodes id: Long, label: Int, features: Array[Float] Raw unmodified node features and labels streamed directly from source.
nodes id: Long, label: Int, features: Array[Float] Distributed copy partitioned for optimal SQL join locality.
original_edges src: Long, dst: Long Raw directed edge list exactly as provided by the dataset source.
edges src: Long, dst: Long Undirected, deduplicated, self-loop-free canonical graph.
masks id: Long, split: String Official OGB or stratified masks ('train', 'valid', 'test').
Dynamic Volume Discovery Disk Safety

Scans all candidate EBS mounts (/mnt/tmp, /mnt/spark) to redirect huge temporary dumps and caches away from the 15GB root volume, eliminating EMR Driver disk crashes.

Memory-Mapped Numpy Reads Zero-Heap

Uses mmap_mode='r' to access multi-gigabyte feature arrays (e.g. 111M-node papers100M) without allocating memory on the Python or JVM heap.

Chunked Micro-Batch Streaming Streaming

Streams nodes in 200,000-row batches and edges in 2,500,000-row batches to S3 Delta Lake via PySpark DataFrame appends, ensuring fixed bounded RAM.

phases/phase0_ingestion.py — Chunked Node Streaming to Delta Lake 
# Define explicit Spark schema with Float Array feature vectors
ns = StructType([
    StructField('id', LongType(), False),
    StructField('label', IntegerType(), True),
    StructField('features', ArrayType(FloatType()), True)
])

CHUNK = 200000
for s in range(0, n_nodes, CHUNK):
    e = min(s + CHUNK, n_nodes)
    pdf_nodes = pd.DataFrame({
        'id': np.arange(s, e, dtype=np.int64),
        'label': np.nan_to_num(lbl[s:e], nan=-1).astype(np.int32),
        'features': node_feat[s:e].tolist()
    })
    df_node = spark.createDataFrame(pdf_nodes, schema=ns)
    df_node.write.format('delta').mode('overwrite' if s == 0 else 'append').save(p['original_nodes'])
🔄 Zero-Driver-RAM Graph Symmetrization & Deduplication

To construct undirected canonical edges without pulling 1.6 Billion edges to driver memory, Phase 0 performs a distributed self-union and deduplication directly inside Spark across YARN worker executors:

phases/phase0_ingestion.py — Distributed Spark Edge Symmetrization 
orig_df = spark.read.format('delta').load(p['original_edges'])

# 1. Generate reversed edges (dst -> src)
rev_df = orig_df.selectExpr("dst as src", "src as dst")

# 2. Union, filter out self-loops, and deduplicate across executors
sym_df = orig_df.union(rev_df).filter("src != dst").dropDuplicates(["src", "dst"])

# 3. Write directly to S3 Delta Lake
sym_df.write.format('delta').mode('overwrite').save(p['edges'])

1. Distributed Label Propagation on Spark Workers

LPA runs in parallel across all cluster nodes. In each iteration, nodes broadcast their current community label across connected edges, and each node adopts the majority label proposed by its neighbors.

phases/phase1_community.py — Distributed LPA Inner Loop 
# 1. Initialize node states (community_id = id)
curr = nodes_df.select('id').withColumn('community_id', F.col('id')).repartition(num_parts).cache()

for i in range(lpa_max_iter):
    curr_rename = curr.withColumnRenamed('id', 'src').withColumnRenamed('community_id', 'src_comm')
    
    # 2. Join with edges to pass community labels from source to destination
    proposed = edges_df.join(curr_rename, on='src', how='inner') \
                       .select(F.col('dst').alias('id'), F.col('src_comm').alias('proposed_comm'))
    
    # 3. Frequency aggregation & mode label selection
    freq = proposed.groupBy('id', 'proposed_comm').count()
    best = freq.select('id', F.struct('count', 'proposed_comm').alias('c_info')) \
               .groupBy('id').agg(F.max('c_info').alias('best_info')) \
               .select('id', F.col('best_info.proposed_comm').alias('new_comm'))
    
    # 4. Truncate Spark Catalyst lineage via local checkpoint every 2 iterations
    curr = curr.join(best, on='id', how='left') \
               .withColumn('community_id', F.coalesce(F.col('new_comm'), F.col('community_id'))) \
               .select('id', 'community_id').repartition(num_parts)
    
    if i % 2 == 1:
        curr = curr.localCheckpoint()
    else:
        curr = curr.cache()

2. Driver-Side Louvain & Fast ID Remapping

To achieve higher community modularity, EMO collects the canonical edges into the Driver memory and executes C-accelerated Louvain multilevel partitioning using igraph:

1. Half-Edge Filter 50% Memory

Applies src < dst filter in Spark before .toPandas(). Because the graph is undirected, this cuts transfer memory exactly in half.

2. Vectorized Binary Search O(E log V)

Uses np.searchsorted on unique vertex IDs to map arbitrary 64-bit sparse node IDs to dense 0..V-1 integers in C without Python loop overhead.

phases/phase1_community.py — Driver Louvain Collection & ID Mapping 
# 1. Collect only canonical upper-triangle edges to driver RAM
edges_pd = (edges_df
            .filter(F.col('src') < F.col('dst'))
            .select(F.col('src').alias('u'), F.col('dst').alias('v'))
            .toPandas())

# 2. Vectorized C-speed ID remapping via NumPy binary search
all_nids = np.union1d(edges_pd['u'].values, edges_pd['v'].values)
u_mapped = np.searchsorted(all_nids, edges_pd['u'].values)
v_mapped = np.searchsorted(all_nids, edges_pd['v'].values)

# 3. Build native igraph and run Louvain multilevel optimization
el = zip(u_mapped, v_mapped)
G = ig.Graph(n=len(all_nids), edges=el, directed=False)
partition = G.community_multilevel(resolution=resolution)

# 4. Map back to original 64-bit global IDs and parallelize back to Delta
id_to_comm = {}
for ci, members in enumerate(partition):
    for li in members:
        id_to_comm[int(all_nids[li])] = ci

comm_rows = list(id_to_comm.items())
cschema = StructType([
    StructField('id', LongType(), False),
    StructField('community_id', LongType(), False)
])
communities_df = spark.sparkContext.parallelize(comm_rows).toDF(cschema).cache()
communities_df.write.format('delta').mode('overwrite').save(p_alg['communities'])
